## Narrative
As a registered user I want to sign in to my account so that I can access the product — via the Sign-In page designed in Figma, in English and Persian.

## Business logic
- Sign-In screen matches the Figma design exactly (R1). Local spec: `docs/figma/Sign In (EN).png`, `docs/figma/Sign In (FA).png` (inactive) and `Sign In (EN) Active.png`, `Sign In (FA) Active.png` (active-state screens).
- Both English and Persian variants exist; FA copy per R2 (e.g. «ورود به اکانت», «ورود با حساب گوگل/فیسبوک», «آدرس ایمیل», «رمز عبور») incl. direction handling.
- Sign-In has no `Full Name` field (only Email Address + Password per the screens); footer link «حساب کاربری ندارید؟ بسازید» / `No Account? Create One!`.
- Stack: plain HTML/CSS/JS (R3).
- What happens on sign-in submission (session, navigation, persistence) is **Unknown** — no backend claim exists yet.
